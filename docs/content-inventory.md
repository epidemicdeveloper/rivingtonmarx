Project photographer credits remain in source copy. No content claims have been invented.

The preview contact form requires a separate mail provider integration and must be marked as a demo. Original privacy text describes the existing website and requires review before launch. Original punctuation is retained. Some Windows console output displayed replacement glyphs, but the JSON has no Unicode replacement characters. The original source remains available for comparison.
One source press image (https://rivingtonmarx.com/wp-content/uploads/2026/03/8.png) could not be downloaded and is omitted. The press article links remain available.
